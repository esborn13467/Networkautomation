About 1 minute. This is the system architecture in two layers. The top layer is the Zero Trust network in Containerlab: the switches, FreeRADIUS, the edge firewall, the DMZ and the user PCs. The access switch mirrors all user traffic down to the SIEM host. There, a Python pipeline runs left to right: the collector reads packets from the mirror port, the feature builder turns each PC's traffic into eight numbers every ten seconds, the Isolation Forest scores the window, with one extra rule for repeated failed logins, the classifier names the attack type, and the response engine acts. The actions go back up to the network: SSH commands to the switches, and rules in FreeRADIUS. Every score and action is also sent to Zabbix for the dashboard and email alerts.
