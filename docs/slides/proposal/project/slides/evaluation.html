Zero Trust network with automated threat detection · Esborn Kihiu

9 / 11

About 1 minute 15 seconds. I prove the system works with four kinds of test. First, policy checks: after every rebuild a script confirms that each role can reach only what it should, for example a guest can reach the DMZ web server but not a staff PC. Second, 802.1X: the right password lands the user in the right VLAN, and a wrong password leaves the port closed. Third, the detector: 594 normal windows and 100 attack windows, five attack types at five intensities, scored with five-fold leave-one-run-out cross-validation so every run is tested by a model that never saw it. Fourth, end to end: each attack is launched live while the other PCs work normally, and I time how long it takes from the end of the window to the action. The results on the right: 99 percent accuracy, every attack window detected, 1.1 percent false alarms, which only raise an alert and never block a user, and under two seconds from detection to action. The final rehearsal on 16 GB answered all five attacks in 1.1 to 1.9 seconds.
