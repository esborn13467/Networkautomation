Zero Trust network with automated threat detection · Esborn Kihiu

7 / 11

About 1 minute. These are the actual systems. Everything runs in Containerlab on one Kali Linux laptop, and the whole lab is rebuilt with one command. The two switches run real Arista EOS software, so they behave like production switches. FreeRADIUS does the 802.1X logins with PEAP and returns the VLAN. The edge is a Linux router with an iptables default-deny firewall and a DMZ web server. Detection is Python with pandas and scikit-learn. The response engine uses Netmiko to log in to the switches over SSH. Zabbix gives the dashboard and emails alerts. I chose real software over Packet Tracer because Packet Tracer gives no real packets for the detector and Python cannot log in to it to apply a response.
