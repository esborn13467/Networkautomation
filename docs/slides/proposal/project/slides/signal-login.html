About 1 minute. The first signalling diagram is the 802.1X login, which is the identity half of Zero Trust. The PC starts with EAPOL-Start. The switch asks for an identity, and the PC answers with the username, here alice. The switch forwards it to FreeRADIUS in an Access-Request. Inside a PEAP tunnel the password is checked. If it is correct, RADIUS sends Access-Accept with a VLAN attribute, the Tunnel-Private-Group-Id, set to 20 for staff. The switch then opens the port in VLAN 20. If the password is wrong, RADIUS sends Access-Reject and the port stays closed, so no traffic gets through before a login.
