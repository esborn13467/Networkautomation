About 1 minute. The second signalling diagram shows detection and response, using a port scan from the guest PC as the example. One: the guest PC probes ten or more ports. Two: the access switch mirrors that traffic to the SIEM host. Three: at the end of the ten-second window the Python pipeline builds eight features, the Isolation Forest scores the window as an anomaly, and the classifier names it a port scan. Four: the response engine writes a rule into FreeRADIUS that puts this user in VLAN 99. Five: it logs in to the access switch over SSH with Netmiko and bounces the port. Six and seven: the PC logs in again and RADIUS now places it in quarantine VLAN 99. Eight: the event goes to Zabbix, which raises an alert and emails the administrator. The other attacks follow the same pattern with a different action: a DoS source is blocked by a deny line in the core ACL, and an insider has the account disabled.
