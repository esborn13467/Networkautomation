About 1 minute. This is the technical design. Every user sits in a VLAN chosen by their role: admin VLAN 10, staff VLAN 20, guest VLAN 30, and VLAN 99 for a quarantined host. All users connect through the access switch, which runs 802.1X on every port and asks FreeRADIUS who the user is. The core switch routes between the VLANs, and the ZT_POLICY access list enforces least privilege. The edge firewall is default deny and protects the inside from the DMZ web server and the internet. The access switch also copies all user traffic to the SIEM host, which is where detection runs. So RADIUS answers who you are, and the SIEM answers what you are doing. The policy line at the bottom is the analysis of who may reach what.
