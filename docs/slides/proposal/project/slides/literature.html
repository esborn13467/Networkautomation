About 1 minute 30 seconds. The review covers the five areas you asked for. Networking: VLANs and ACLs are the basic tools for segmentation. Systems: 802.1X with a RADIUS server gives authentication, authorization and accounting, and with dynamic VLAN assignment the VLAN follows the user, not the port. Cloud: cloud services and remote work removed the clear inside and outside, which is why organisations are moving to Zero Trust; container technology also lets me run real switch software on one machine. Applications: Isolation Forest is an unsupervised algorithm, so it does not need labelled attack data. Cybersecurity: signature tools miss new behaviour, and automating the first response shortens the time an attacker has. The gap: these are usually studied separately, and few working systems connect detection directly to the network controls. That is what this project does.
