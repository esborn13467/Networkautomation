The data came from the lab itself: four ten-minute normal runs, and five runs of each attack at five intensities, including very weak attacks, for example brute force at one guess per second. I used five-fold leave-one-run-out cross-validation, so every run was scored by a model that had never seen it. Labels were only used to measure the results. The threshold was tuned on a separate normal run.
