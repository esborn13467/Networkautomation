What was built

Three layers working together

LAYER 1

Zero Trust network

Nobody gets on without an 802.1X login. RADIUS places each user in the VLAN for their role. ACLs and a firewall limit every segment.

LAYER 2

Detection

A mirror port copies user traffic to the SIEM. Python builds 8 features per PC every 10 seconds, and an Isolation Forest scores each one.

LAYER 3

Automated response

Each attack type gets its own action: block, quarantine, disable the account or alert. Every step shows up in Zabbix.

The system has three layers. The first decides who may connect and where they may go. The second watches what each device does once it is inside. The third acts on what the second finds, without waiting for a person. The important part is that the response uses the Zero Trust controls themselves: the ACL to block, and the identity-based VLAN to quarantine.
