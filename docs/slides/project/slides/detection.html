The access switch copies all user traffic to the SIEM host. Every ten seconds the pipeline turns each PC's traffic into eight numbers, the features from Chapter 4. Failed logins come from the RADIUS log. The Isolation Forest isolates unusual windows in fewer random splits, which gives them a higher score. One policy rule catches slow password guessing, which the model alone could not see. A flagged window is then classified from its features.
