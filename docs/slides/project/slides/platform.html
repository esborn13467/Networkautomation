The response engine has to log in to the switches and the detector needs real packets. Packet Tracer offers neither, so the design was rebuilt on Containerlab, with FreeRADIUS in place of Cisco ISE.

Zero Trust network with automated threat detection · Esborn Kihiu

7 / 18

The proposal planned Packet Tracer and Cisco ISE. In the first phase I found that Packet Tracer cannot be reached by Python over SSH and gives no real packets, so automated detection and response would have been impossible. Containerlab runs real Arista switch software in containers on one laptop. FreeRADIUS replaces ISE and does the same job: 802.1X and VLAN assignment by identity. The security design itself did not change.
