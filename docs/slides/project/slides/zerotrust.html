A port stays closed until the user logs in with 802.1X. FreeRADIUS checks the password and returns the VLAN, so the VLAN follows the user's identity, not the port. Guests reach only the DMZ web server and the internet. A quarantined host may only log in again and be investigated. A wrong password leaves the port closed. I will show this live in a moment.
