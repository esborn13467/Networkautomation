Zero Trust network with automated threat detection · Esborn Kihiu

2 / 18

Most enterprise networks still trust a device once it is inside. If an attacker gets in, or a staff account is misused, there is little to stop them moving between systems. Signature-based tools only catch what they already know, and the response waits for a person. Zero Trust answers the first problem: never trust, always verify. Machine learning helps with the second: noticing behaviour that does not look normal. My project combines the two and adds an automatic response.
