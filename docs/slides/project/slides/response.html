This follows the Chapter 4 activity diagram. A DoS source is blocked on the core switch. A scanning or password-guessing host is quarantined: RADIUS moves the user to VLAN 99 and the port is bounced, so the PC logs in again straight into quarantine. An insider copying data has the account disabled. Off-hours work and anything unclassified only raise an alert. That design choice matters: the few false alarms never block anyone.
