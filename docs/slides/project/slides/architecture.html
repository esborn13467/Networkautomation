Architecture

The network as built

  • Two Arista cEOS switches: core and access
  • FreeRADIUS for 802.1X logins
  • Linux edge firewall and a DMZ web server
  • Admin, staff and guest PCs, each in its own VLAN
  • SIEM host receives a copy of all user traffic
  • Zabbix monitors all nine nodes
  • Runs on one laptop and rebuilds with one command

5 / 18

This is the network as built, Figure 4.7 in the report. Users connect through the access switch, which checks their login with FreeRADIUS. The core switch routes between the VLANs and enforces the policy ACL. The edge firewall protects the inside and hosts the DMZ. The access switch copies all user traffic to the SIEM host, where the detection pipeline runs. The red lines are the automated responses: a block on the core, or a quarantine through RADIUS.
